# Worked GitHub Copilot Repo

This example shows a Copilot-first repository setup with policy, path instructions, staged agents, and prompt-file entry points.

## What This Example Demonstrates

- repo-wide policy in `.github/copilot-instructions.md`
- shared cross-tool memory in `AGENTS.md`
- path-specific instructions for testing and architecture
- prompt files for narrow recurring jobs
- staged custom agents for research, implementation, review, and release posture

## Surface Warning

Prompt files and advanced agent behavior are strongest in VS Code-style Copilot surfaces. Keep a fallback path to repo instructions and direct prompting when unavailable.
