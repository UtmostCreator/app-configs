# Generated Artifacts Policy

Do not manually edit generated artifacts.

Each generated artifact should map to:

- artifact path
- source inputs
- generator command
- check command
- committed status

Use validator: `php tools/ai/validate-generated-artifacts.php`.

If generated outputs drift, regenerate using documented commands and include the output in the same change.

## Commit Policy

| Artifact location | Committed | Notes |
| --- | --- | --- |
| `docs/ai/catalog.md`, `llms.txt`, `packages/ai-universal-rules/catalog.json`, `packages/ai-universal-rules/docs/BROWSE.md`, `docs/ai/repo-required-tools.md` | Yes | Canonical baseline; required present and enforced by `tools/ai/validate-generated-artifacts.php`. |
| `docs/ai/generated/**` | No | Git-ignored except `README.md` and `sessions/.gitkeep`. Regenerate locally with `php tools/ai/ai.php <command>` or `php tools/ai/generate-repo-structure.php`. |
| `docs/generated/**` | No | Git-ignored except `README.md`. Regenerate locally. |
| `.ai-logs/**`, `.copilot-logs/**`, `.repomix-context/**`, `.ai-backups/**`, `.ai-tmp/**` | No | Runtime-only; never commit. |

To rehydrate the ignored generated folders, run the generator commands listed in
each folder's `README.md`. The `docs/ai/generated/artifacts.json` manifest is
itself regenerated by the same commands and is not committed.

## Runtime Session Logs

AI session handoff logs under `docs/ai/generated/sessions/SESSION_ID/` are runtime-generated artifacts. Create and validate them with:

- generator commands: `php tools/ai/session-start.php`, `php tools/ai/agent-log.php`, `php tools/ai/session-end.php`
- check command: `php tools/ai/validate-session-log.php <session-id-or-path>`

Do not manually add secrets or raw private prompts to session logs.
