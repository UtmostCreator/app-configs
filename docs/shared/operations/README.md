# Operations

Runbooks. What you open when something is on fire, written to be followed under
pressure: numbered steps, exact commands, expected output, and the rollback.

| Area | Holds |
|---|---|
| [`security/`](security/README.md) | vulnerability handling, advisories, secret rotation, incident response |

Add one file per runbook and link it here. A runbook nobody can find during an incident
is a runbook that does not exist.
