# Archived work

Closed tickets, investigations, and releases are retained by year:
`archive/<yyyy>/<work-id>/`.

Material whose year is not known yet, such as an import from an older layout, goes under a descriptive folder like `archive/legacy-tickets/` or `archive/legacy-investigations/`. Give each folder a `README.md` that lists what it holds. Where a work item sits in the archive says where it was filed, not that it is closed.

Move, never delete. Preserve the received request, decisions, findings, and evidence;
distill durable facts into `docs/shared/` rather than treating archived work as current
guidance.
