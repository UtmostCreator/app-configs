# Archived AI-kit tests

`SessionLogToolsTest.php` is part of the AI Workflow Kit (it `require_once`s
`tools/ai/session-log-lib.php` and exercises `tools/ai/*.php`). The AI kit was
removed from this repo, so the test is parked here to keep `tests/` limited to
runnable, repo-owned tests. It is restored when the AI kit is reinstalled
(uncomment `ai:test:php` in `mise.toml`).
